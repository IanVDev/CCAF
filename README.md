# CCAF Solo Mode

Sistema solo de preparação para o **Claude Certified Architect Foundations (CCAF)**, pensado para zero fricção.

## Como usar

1. Abra o arquivo `CCAF_SOLO_MODE.md`
2. Vá para qualquer dia (D1 a D14)
3. Copie o Prompt de Missão
4. Cole no Claude
5. Estude

## Estrutura de cada dia

- Objetivo do dia
- Foco temático
- Fontes prioritárias
- Prompt pronto para usar
- Questões estilo prova com correção comentada
